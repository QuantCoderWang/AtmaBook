# AtmaBook — 离线旅行攻略地图本&地理照片合辑

> 一款以地图为主画布的 Flutter 离线旅行攻略应用：图文标记游玩地点、自动聚类“必去”点生成游览片区与推荐路径、带 GPS 的照片与视频铺成地理相册、一键打包为单文件攻略与他人分享或作为永久备份。
> **全量数据仅存于本机，不依赖任何服务器、不注册任何账号。**

## 一、项目定位

AtmaBook 面向三类真实场景：

| 场景 | 说明 |
| --- | --- |
| **旅行规划** | 以地图为画布标记“想去”的地点（景点 / 餐饮 / 购物 / 住宿 / 交通），系统自动把“必去”点聚类成片区并生成推荐游览路径，将目标城市的游览点聚类并拆解为数个“游览区域”。 |
| **行程整理** | “攻略笔记”把攻略即时重排为一篇可通读的行程文档：住宿为起点、片区按距离排序、图文坐标全部可点击导航——此为纯派生视图，零新增存储。 |
| **旅行事后归档与分享** | 旅行归来后，带 GPS 的照片与视频（注意拍照请打开GPS定位功能，未标记坐标也可以后期手动调整标注）自动归入地理相册并落回地图；任一攻略可打包为单个 `.tgshare` 文件发送给朋友（接收方一键导入）或自留作永久备份。 |

应用形态为 **Flutter 无服务器（offline-first）应用**：全部业务数据（攻略 JSON、图片、视频、离线瓦片）保存在应用数据目录内，应用数据可直接整体备份与迁移。

**交付平台**：Windows 桌面版本与 Android版本为目前已交付打包应用；iOS / Linux / Web 为预埋工程（iOS / Linux 须在对应操作系统上构建，我没有做构建，有需要请自行构建，Web版本用于开发中预览）。

## 二、项目理念

1. **数据主权优先**。攻略、照片、视频的所有权属于用户。应用不设立任何云端服务：写入即本地落盘，导出即标准格式（JSON + 通用图片/视频文件），卸载不产生任何残留依赖。
2. **离线是一条主线，而非降级路径**。从离线瓦片下载向导、离线瓦片渲染 Provider，到纯 Dart 的 EXIF 解析、聚类与路径算法，核心能力在无网络状态下完整可用；在线能力（在线底图、地理检索、路网规划）均为可插拔增强。
3. **照片与地理信息的天然融合**。照片的 EXIF（GPS + 拍摄时间）与标记的坐标把“去过哪里”变成可检索、可视化的数据；视频以首帧缩略与时元入册，与照片共用同一套逻辑。
4. **分享与副本语义严格分离**。分享出去的是降质加水印的副本（也可以选择不分享降质副本），本地原件永不受影响；导入的一律是重映射 ID 的独立副本，与现有数据零冲突。
5. **界面即笔记**。视宽覆盖列表 / 网格 / 地图 / 相册 / 行程笔记多种形态，让一次旅行的信息团以最直观的形态呈现，而非单一数据库视角。

## 三、功能总览

### 3.1 攻略管理

- 笔记本风格首页：攻略卡片（封面 / 标题 / 标记数 / 更新时间），支持列表与网格双形态、标题与简介检索；
- AppBar 快捷图标：检索 / **地理相册**（独立图标入口）/ ☰ 菜单抽屉；
- 攻略创建向导（基础信息 → 范围检索）：关键字检索城市与地点（Nominatim 免密钥 / 高德 Key 选配），自动判断攻略落点境内境外并推荐底图，检索结果与离线地图包存在性联动（已有可直接用，缺省一键下载）；
- 攻略信息编辑（标题 / 简介 / 封面插图）、可彻底删除（连带图片文件清理）。

### 3.2 地图与标记

- `flutter_map` 渲染，多种底图源随时切换：高德矢量 / 高德卫星 / Esri 街道 / 地形 / 浅灰 / 卫星（全部免密钥）、OSM、天地图与离线瓦片包；
- 长按地图添加标记（收录景点 / 餐饮 / 购物 / 住宿 / 交通 / 其他六大预设分类，可自定义颜色与图标）；点击标记弹出图文详情并支持导航跳转；
- 双标记样式系统：图标式 Pin（默认）与彩色大头针，全局设置切换，两类样式均支持必去星标、片区色环与自定义图标；
- 标记列表侧抽屉：按分类 / 片区筛选排序、一键定位。

### 3.3 片区聚类与推荐路径

- **DBSCAN** 聚类“必去”点生成片区（半径 1–20 km 与最少点数均可在设置页调整），孤立点单列成区；片区产生**重叠时自动消解**（主片区保持范围、次片区收缩半径，最小保底 400 m）；
- 片区内路径：最近邻构造 + **2-opt** 迭代优化的开放路径 TSP 启发式；在线模式下经 **OSRM**（免密钥 Demo 服务）将路线吸附至实际路网，离线 / 失败时回退直线虚线示意；
- 片区配色按 HSV 色环均匀采样并与图例、Pin 外圈、路线同色联动。

### 3.4 离线地图

- 三段式下载向导：地图上对角两角框选范围 → 勾选缩放级别区间 → 预估张数（超阈值二次确认）→ 并发下载（4 并发、失败重试 2 次、UA 标识、节流、任意中断续传跳过已存在、取消令牌即刻生效）；
- 下载前提供**连线测试**（单瓦片实测，验证源可达性与耗时）；
- 离线管理页：包体积实测、本地片数统计、一键删除（连文件）；
- 渲染端 `OfflineTileProvider`：本地命中优先 → 在线回退 → 纯离线灰块，配合 `ImageCache` 复用防止重复解码。

### 3.5 地理相册（照片 + 视频）

- 双来源聚合：各攻略内照片（`g:` 条目）与全局账本（`w:` 条目）合并去重，按拍摄时间取样上限控制（默认 200，20–500 可调）；
- **白板地理墙**：有定位照片按 ≤150 m 贪心聚团，围绕簇心以确定性伪随机偏移与 0–45° 倾角叠放，年轴滑轨贯通历年（同 seed 布局可复现，用于按年导出）；
- **相册库**：全部条目登记簿（时间倒序，视频条目附时长显示），支持逐一补写 / 修改地理定位（选点地图）、修改归属攻略、**剔除显示项（不删除原始文件，可随时恢复）**与删除；
- 导入链：EXIF 白名单解析 → 内容哈希判重 → 原图落盘 → 缩略图生成 → ≤5 km 就近自动归属攻略 → 账本落库；批量 / 精选（多选逐张勾选）/ 目录自动扫描三种入口；
- **视频插入**（仅经地理相册入口）：流式哈希（FNV-1a 采样）与流式复制处理大文件，ffprobe 探时长、ffmpeg 提取首帧生成缩略（注意：需使用三方插件），入册后经查看器手动补写地理位置，之后与照片完全同构。

### 3.6 攻略笔记（自动生成）

- 纯派生视图：不新增任何存储与手写入口，打开即从攻略既有数据实时抽取；
- 内容编排逻辑：多住宿单选作为游览起点 →「本次住宿 · 游览起点」卡片 → 片区按起点距离升序 → 每片区范围标记（设定半径 + 实际覆盖面积）→ 必去点靠前的游览点列表 → 圈内餐饮 / 购物推荐 → 圈外其余推荐平铺；
- 无“必去”点时自动回退为类别平铺视图（住宿置顶）并给出引导文案；
- 全部坐标可点击导航（桌面跳转地图默认高德 · 公交）。

### 3.7 分享与导入（.tgshare）

- 单文件 ZIP 容器：`manifest.json` / `guide.json` / `cover.*` / `photos/` / `thumbs/` / `images/` 与 `videos/` + `videos.json`；读取端向下兼容历史格式包；
- 双打包模式（导出弹窗分支选择）：
  - **水印低质版**（默认）：可选是否包含照片，实时预计体积；所有导出图片（含封面）缩放为低质量 JPEG 并**烧录横向平铺水印**；视频转码 ≤720p H.264 并烧录斜向平铺水印；
  - **原片高清版**：照片 / 插图 / 封面 / 视频**按原件字节入包**（不缩放、不转码、无水印），**无 ffmpeg 也能导出**；包体硬上限 **1 GB**，超限提示「删除部分照片或降低照片质量」，提供内容筛选与两档降质（长边 2048·q85 / 1080·q80，副本仅存在于包内，原图只读、临时副本打包完成即清除）；**账本归属照片 / 视频一并纳计**（经相册归属进攻略的媒体按 `guideId` 注入分享链，guide.json 随包落盘、按 id 幂等去重）；筛选清单显示名 = 自定义名 → 空名回退拍摄时间（与照片查看器同口径）；
- 导出落盘：桌面写入下载目录，Web 触发浏览器下载（原片模式仅桌面与移动端可用）；
- 导入：manifest 校验 → FNV-1a64 指纹查重（重复提示可再导为副本）→ **全量 ID 重映射**（攻略 / 标记 / 照片 / 片区成员全部重写内部引用）→ 条目白名单与路径穿越防护（拒绝 `../`、绝对路径、盘符）→ 入库并标记 `shared`，封面角标与「（分享）」后缀标识；
- **隔离口径**：`shared` 攻略的照片与视频不进入用户本地地理相册，用户对其的本地增删均为副本语义；原片包导入的攻略额外标记 `sharedOriginal`，**允许再次导出原片**（备份链可延续），水印副本同样可通过导出弹窗再打包（产物仍为水印副本）；
- **全量导出包**：☰ 菜单「全量导出」把攻略本**全部攻略逐个按原片模式**（封面 + 标记插图 + 攻略内照片 + 账本归属照片 / 视频，全部原画质直通）打包成**单个 `.tgbundle` 大包**（外层 ZIP 容器 + 序号命名的内层 `.tgshare`），**不限制总体积**（1 GB 上限仅约束单个原片分享包）；导入沿用「加载分享」入口按扩展名分流，逐条流式复原（同一时刻仅一个内层包驻留内存），已导入过的攻略按包内指纹**自动跳过**，结果以「成功 n · 重复 m · 失败 z」汇总；用于文件迁移与多设备共享（`docs/补充功能-全量导出包.md`）。

### 3.8 系统设置与国际化

- 全局设置：标记样式、片区聚类参数、服务密钥（高德 Web Key / 天地图 tk，选配）、分享水印文字、相册目录与取样上限；
- **分类管理**：设置页「地点分类」卡片——内置六大分类可改配色与图标；支持**自定义分类**（新增 / 改名 / 删除，删除时已引用标记自动回退「其他」）；各分类可上传 **1:1 图片图标**（长边钳制 512、正方形校验）并入 Pin 图标体系；单标记仍可独立自定义 Pin 颜色与图标；
- **界面语言**：中文（默认）/ English / 跟随系统，切换即时生效；跟随系统在读出非中英语言时回退中文；587 双语词条，Material 内置文案同步挂载三委托。

## 五、关键技术要点

1. **坐标系三层分离**：所有持久化数据（标记、照片 EXIF、聚类、瓦片包范围）统一 **WGS-84** 十进制度；高德 / 天地图瓦片按各自坐标系（GCJ-02、CGCS2000）在**渲染时实时换算**，WGS84→GCJ02 单向偏移往返误差 < 1 m，保证点位在不同底图上不漂移。OSM/Esri 瓦片数学按球面墨卡托直接命中；GCJ 源换算后再算瓦片号。
2. **确定性布局算法**：相册墙的聚类 / 锚点网格 / 成员偏移实现为纯函数（固定 seed），同输入必现同输出——既保证截图预览与实际渲染一致性，也支撑按年快照导出的可分享照片墙。
3. **纯 Dart EXIF 白名单解析**（`exif_gps.dart`）：APP1 → TIFF（双字节序）→ GPS 子 IFD（度分秒→十进制、S/W 取负、越界保护）+ DateTimeOriginal；任何畸形数据安全返回空，不引入原生依赖。
4. **内容哈希去重**：照片原图与视频均以内容哈希命名落盘（`pics/videos/v_<哈希>.<ext>`），同素材重复导入不产生冗余文件而计入 dupe 计数。
5. **原子性与一致性**：所有 JSON 写入经由写队列执行**原子替换**（写临时文件后 rename）；分享导入失败时删除半成品目录回滚；账本与年快照合并一次性写入。
6. **国际化双通道**：UI 层 `AppLocalizations.of(context)`；无 BuildContext 的服务层（导出进度、扫码报告、下载统计）统一走 `I18nService.t`（静态 getter，由 `localeResolutionCallback` 同一 Locale 同步），两通道同源同构；ARB 占位符全部采用位置参数。
7. **动态视口加载**：相册地图与照片墙按缩放级 bucket 与视口（含 15% 余量）动态计算可见集合，配合 64px 聚合格 ≥2 点合并为数量气泡，控制大规模标记数下的建帧成本；账本异步加载后主动补算一次（修复打开即显问题）。
8. **跨平台降级矩阵**：桌面真实文件系统 / Web 端 `shared_preferences` + base64 降级（≤1 MB blob）；文件夹扫描以 conditional import 三态实现（IO / Stub / 注册表）；视频转码 / 首帧提取依赖本地 ffmpeg（Windows，获取方式见「构建与运行」）并在不可用时降级为渐变占位缩略（不阻塞业务）。

## 六、开发难点与解决方案

| # | 难点 | 解决方案 |
| --- | --- | --- |
| 1 | 官方 `video_player` 无 Windows 原生实现 | 播放层改用 **media_kit**（mpv 内核）：Windows / Android 硬解成熟，字幕 / 倍速 / 进度开箱可用；iOS / Linux 由 `media_kit_libs_ios_video` / `media_kit_libs_linux` 接管。 |
| 2 | FFmpeg 滤镜文案难以绘制中文且规则脆弱 | 水印烧录改为 **Flutter 引擎侧合成**（`PictureRecorder`/`Canvas` + `TextPainter` 以系统字体绘制半透明白字黑描边）；视频侧斜向平铺水印采用 ffmpeg `drawtext` 方案，实践中收集到四条关键教训：滤镜表达式**逗号转义**、须 GPL 构建（含 libx264）、`-hwaccel auto` 带来 6× 硬解提速、`-aac_coder fast` 规避 AAC 与 libx264 并发死锁。 |
| 3 | 国产相机 / 相册导出照片可能被剥离 EXIF，无 GPS 照片无法定位 | 采用“不放弃、不冒认”口径：无 GPS 照片照常入册进「未定位」栏，支持查看器内点选地图**手动补写定位**，写入后按就近规则自动归属攻略 —— 全程按计数明确提示。 |
| 4 | Web 端无文件系统 | `StorageAdapter` 抽象双实现：JSON 文本入 `shared_preferences` 键、字节 ≤1 MB 转 base64 直存（封面可跨会话保留）、更大对象仅存会话内存；自定义 UA 头在 Web 端改造（避免 CORS 预检整包拦截），瓦片源可达性在下载向导前置连线测试。 |
| 5 | 离线瓦片投影计算正确性 | 首版 y 轴公式存在 2π 因子错误；以**手算 16 张口径**建立 `tile_math` 单元测试基线（含退化框、越界、GCJ 同瓦片比对），杜绝回归。 |
| 6 | 无 BuildContext 场景的用户可见文案 | 建立服务层取词通道 `I18nService`，进度回调 / 报告 getter（如 `WallScanReport.banner`、瓦片下载统计 `toString`）在 getter 内自取词，调用方签名零改动；同时约束仅用户可见消息参与翻译，内部异常文本与 debugPrint 不纳入。 |
| 7 | 大图水印导出阻塞 UI | 逐张处理（解码 → 缩放 → Canvas 合成 → JPEG 编码）配进度条与取消开关，批次作业排在事件间隙执行。 |
| 8 | 导入分享文件的路径穿越与体积风险 | ZIP 条目名白名单 + 字符集校验，绝对拒绝 `../`、绝对路径、盘符；单文件 500 MB 上限与累计解压配额。 |
| 9 | 片区重叠导致图例与视觉混乱 | `ZoneLayout` 纯几何后处理：成员多者为主片区保持范围，次片区向新中心收缩（保底 400 m），逐对消解后重算基线。 |
| 10 | 高德移动端相册通道兼容性 | 照片导入移动端统一走 `image_picker` Photo Picker（免 Android 13+ 存储权限），桌面端 `file_selector` 双轨；iOS 分享文件选择补 `uniformTypeIdentifiers`。 |
| 11 | 分享防翻录 | 水印**烧录进像素**且不可逆（水印低质版恒烧录；原片高清分支供全画质共享 / 备份）；地理相册对 `shared` 照片过滤，防止分享副本混入用户图库。 |

- 注意：部分解决方案由AI agent提供，可能存在更好解决方案；部分阻塞解决方案由开发者提供，并在编写详细方案后，由AI执行或进行手动修改。

## 八、构建与运行

**本机开发环境要求**：Flutter stable（Dart SDK ^3.13.5，开发环境为 Flutter 3.47 stable）及以上、对应平台工具链。

```bash
flutter build linux                    # 需 GTK 开发库、clang、cmake、ninja、pkg-config

```

## 十一、多语言支持

- **范围**：中文与 English 双语，ARB 架构天然可扩展至更多语言；
