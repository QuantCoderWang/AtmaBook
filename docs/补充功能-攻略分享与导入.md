## 1. 目标与定位

一台**不联网、不依赖任何服务器**的设备上，把一篇攻略连同图文数据打包成**单个文件**，通过任意渠道（微信/网盘/U盘/邮件）发送；接收方用**同一应用**即可一键导入，永久写入本地。

两个用途：
1. **无服务器共享**：攻略作者 → 朋友的点对点传递；接收方得到的是**低质量 + 文字水印**副本图，不损失任何本地化体验；
2. **永久备份**：用户可把自己编写的攻略导出留存，将来任何装有本应用的设备导入即可完整恢复查看（备份数据与共享数据同格式同管线）。

设计原则：**零服务器、零注册、单文件、可校验、导入即副本（不覆盖现有数据）**。

## 2. 分享文件格式（`.tgshare`）

本质是 **ZIP 容器**（纯 Dart `archive` 包读写，双平台一致；发布版可改名后缀防止系统软件误解析）。选择 ZIP 而非自造格式：生态成熟、可用系统工具排查、条目自带 CRC 校验。

```
重庆两日游.tgshare
├── manifest.json          # 信封：格式版本/指纹/导出信息（见下）
├── guide.json             # 攻略结构化数据（Guide.toJson 全量）
├── cover.jpg              # 封面（长边 ≤1280px，JPEG q78）——无封面则无此条目
├── photos/<photoId>.jpg   # 照片低质量副本（长边 ≤960px，JPEG q72）+ 文字水印
└── thumbs/<photoId>.jpg   # 对应缩略（长边 ≤256px，JPEG q70）+ 水印
```

**manifest.json 内容**：
```json
{
  "format": "tgshare",
  "formatVersion": 1,
  "fingerprint": "sha1(guide.json 内容)",
  "sourceGuideId": "gd_xxx",
  "exportedAt": "2026-10-20T18:00:00",
  "appVersion": "0.5.0",
  "watermarkText": "分享照片",
  "includesPhotos": true,
  "counts": { "markers": 12, "photos": 8 }
}
```

**体积预算**（决定「足够小」的实际口径）：
- 低质量副本 ≈ 80–150KB/张；缩略 ≈ 15–30KB/张；封面 ≈ 100–200KB；JSON 数 KB；
- 典型 10 照片攻略 ≈ **1.2–2MB**；30 照片 ≈ 4–6MB；不含照片则 < 100KB。
- 导出弹窗实时显示**预计体积**；后续版本如需再压可加 HEIC/WebP 选项（本期不做）。

## 3. 水印方案（关键技术选型）

**需求**：所有导出图片叠加**文字水印**，默认「分享照片」，设置页可自定义。

**技术路线**：现有 `image` 包的 `drawString` 只内置 ASCII 位图字体，**画不了中文**。故采用 Flutter 引擎侧合成（`dart:ui`，桌面/Web 通用）：

1. `image` 包完成解码 + 缩放 + JPEG 编码（已有 `makeWallThumb` 同款管线）；
2. 字节经 `ui.instantiateImageCodec` 解码 → `PictureRecorder/Canvas` 绘制原图 → `TextPainter` 以系统字体绘制**半透明白字黑描边**（左下角，15° 平铺重复两处，字号随图宽缩放）→ `toImage` → `toByteData(jpeg)` 输出；
3. 逐张处理，导出弹窗显示进度条与「已处理 n/共 m」，支持取消；后台排队执行避免卡 UI。

水印文字随导出实时读设置，**导出的图片已烧死水印**（不可逆），接收方无法通过任何操作还原高清无水印原图——这是「共享不泄底图」的核心保证。

**设置页新增**「分享」卡片：水印文字输入框（默认「分享照片」，空 = 不加水印？不：空则回落默认值），留待您审阅定夺是否提供「关闭水印」选项（建议**不提供**，保持共享图一律水印）。

## 4. 导出流程

**入口**：攻略地图页 ⋮ 菜单新增「**生成分享文件**」（另一入口：首页攻略卡片长按/菜单亦可加，本期只做地图页入口）。

1. 弹出选项卡：
   - ☑ **包含攻略照片**（默认勾选；取消则只导出标记/片区/文本，体积 < 100KB）；
   - 列出将导出的内容摘要（标记 n · 照片 m · 片区 k）与**预计体积**；
   - 水印文字预览（读自设置）。
2. 确认后逐张处理 → 生成 ZIP；
3. 输出位置：
   - **桌面**：写入「下载」目录（`path_provider` getDownloadsDirectory，失败回退文档目录），文件名 `标题-YYYYMMDD.tgshare`，完成后 SnackBar 给出完整路径；
   - **Web**：浏览器端触发下载（Blob + anchor），与日常下载文件一致。

**照片来源约定**：只导出攻略内已落盘的照片文件（`PhotoItem.file` 非空）；旧演示数据无文件的自动跳过并在摘要中注明。

## 5. 导入流程（首页右上 ⋮ 菜单 →「导入分享攻略」）

1. 选择文件（桌面：`file_selector` 打开文件框；Web：`file_selector` 多选/input，同一插件双端可用——需新增依赖）；
2. 解析 `manifest.json`：校验 `format`/`formatVersion`（不识别 → 提示「不是有效的分享文件」）；计算指纹与**已导入清单**比对：
   - 同指纹已导入过 → 弹窗提示「该分享攻略已导入过（于某日）」，可选择「再次导入为副本」或取消；
3. **ID 全量重映射**：为攻略与全部标记/照片/片区成员生成全新 id，重写 `zone.memberIds`、`photo.placeId` 等内部引用——保证与现有任何数据零冲突、可反复导入互不干扰；
4. 图片条目落盘 `pics/<新攻略id>/shared/…`，文字与 JSON 引用全部指向内部副本（与现有照片隔离模型一致）；
5. 永久写入 `guides/<新id>.json`（走 v5.1 写队列原子落盘）+ 索引更新 → 首页即显示；
6. 导入进度弹窗（大文件逐条解压写入），失败回滚（删除半成品目录）。

**首页显示标注（共享识别）**：
- `Guide` 模型新增 `shared`（JSON 键 `shared`，默认 false）——导入的攻略恒为 true；
- 封面**右下角固定绘制分享角标**（`Icons.share` 小徽片，UI 层叠加，非文件水印）；
- 卡片标题渲染为 `标题（分享）`。

## 6. 与「地理相册」的隔离规则（重要口径）

- 分享攻略（`shared = true`）的照片**不进入**用户自己的地理相册：`_unitedAlbumEntries` 聚合时**跳过 shared 攻略**的照片（相册地图与相册库同一函数，天然同时生效）；
- 分享攻略的照片**只在攻略内可见**：攻略地图照片图层、攻略内照片查看器（低质量 + 水印副本）；
- 用户可对分享攻略做本地的标记增删/照片剔除（副本语义，不影响原作者文件）；
- 分享攻略**不可再次生成分享文件**（防止水印图二次分发造成误解）——导出入口对 `shared` 攻略置灰提示。此条若您希望允许「转分享」，请批复时注明。

## 8. 首页菜单重构（解决图标过挤）

**现状**：AppBar actions 依次为 🔍检索 · 排布切换 · 地理相册 · 离线地图 · 设置（5 个，拥挤）。

**目标**：AppBar 仅保留 **🔍检索** + **☰（三横）**；点 ☰ 弹出侧滑抽屉（endDrawer），项如下：

| 菜单项 | 图标 | 行为（原样迁移） |
|---|---|---|
| 切换列表/网格排布 | view_list/grid_view | 原 IconButton 逻辑照搬，图标显示当前将切换到的形态 |
| 地理相册 | photo_outlined | 打开 PhotoWallGalleryPage |
| 离线地图 | map_outlined | 打开 TilesPage |
| **导入分享攻略** | download / archive | **新增**：选择 .tgshare → §5 流程 |
| 设置 | settings_outlined | 打开 SettingsPage |

排布模式等现有状态不变；抽屉头部显示应用名与数据目录提示（诊断友好）。

## 9. 安全与健壮性

- **路径穿越防护**：导入时校验 ZIP 条目名仅允许 `manifest.json|guide.json|cover.jpg|photos/…|thumbs/…` 白名单与安全字符，拒绝 `../`、绝对路径、盘符；
- **体积上限**：单文件 > 500MB 拒绝导入并提示；条目解压累计超限即中止；
- **损坏防护**：ZIP CRC 由 archive 包校验；`guide.json` 解析失败 → 明确报错不写库；
- **导出防呆**：无标记且无照片的空攻略允许导出（备份语义）但弹窗提示。

## 10. 测试与验收清单（开发后执行）

- 单元测试：指纹稳定性；ID 重映射引用完整性（memberIds/placeId 全部重写且不冲突）；`shared` 字段 round-trip；白名单拒绝穿越路径；无照片导出（空 photos 条目）。
- 集成手测：
  1. 导出含照片攻略 → 文件体积符合预算 → 设置页改水印文字后再次导出 → 图上水印已变；
  2. 导入到本机 → 首页出现「标题（分享）」+ 封面角标；地理相册中**无**该攻略照片；
  3. 同文件再导 → 指纹查重提示，选「再次导入」得独立副本；
  4. 改名 `.zip` 可手工打开核对条目（排查友好）；
  5. Web 端导出触发浏览器下载、导入走文件选择，行为一致。

## 12. 待您批复的 3 个默认决定

1. **不提供「关闭水印」**（共享图一律烧水印；仅文字可自定义）——备份自用场景您可随时用应用内原图，分享文件只是便携副本；
2. **分享攻略不可二次转分享**（导出入口对 shared 攻略置灰）；
3. **输出目录**：桌面固定「下载」（失败回退文档目录）+ 完成后 SnackBar 告知路径，不做另存对话框（减少一步操作）。
