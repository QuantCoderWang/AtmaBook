## 0. 阅读前提：三项全局约定

1. **坐标系**：所有存储（标记/照片 EXIF/攻略范围）统一 **WGS-84**；使用高德 GCJ-02 底图渲染时实时偏移换算（`core/utils/coord.dart`）。
2. **存储路径**：JSON 与媒体一律存**相对路径**（基准为应用数据目录 `tourguider/`），整个文件夹可直接备份迁移；绝对路径仅在读取时拼装。
3. **平台能力矩阵**（决定各功能点的"验收平台"）：

| 能力 | Windows 桌面（测试版交付平台） | Web/Edge（M1 界面预览用） |
|------|------|------|
| JSON 文件读写 | ✅ `path_provider` 文档目录 | ⚠️ 无文件系统 → 降级 `shared_preferences` 存 JSON 字符串 |
| pics 媒体拷贝 | ✅ 文件复制 | ⚠️ 降级内存缓存（封面 base64 存偏好设置，照片仅会话内有效） |
| 瓦片落盘下载 | ✅ | ❌ 受 CORS 限制 → 仅演示流程（内存缓存） |
| EXIF GPS 读取 | ✅ 纯 Dart 解析字节，两平台均可 | ✅ 同左 |
| 多点并发网络请求（OSRM/检索） | ✅ | ✅（高德瓦片源除外） |

> 结论：功能验收以 **Windows 桌面为准**；Web 预览保持"能看能点、优雅降级"。桌面运行需先开启系统开发者模式（`ms-settings:developers`，M1 已知事项）。

### M6 完成记录（2026-10-20）

- **数据模型**：`PhotoItem` 重构——`lat/lng` 可空（无 EXIF定位=null）、新增 `file/thumb/placeId/name` 字段（JSON 向后兼容旧演示数据）；旧渐变占位仅当 `file` 为空时兜底渲染。
- **EXIF 解析**：`lib/core/utils/exif_gps.dart` 纯 Dart 白名单实现（JPEG APP1→TIFF 字节序→GPS 子 IFD 度分秒→十进制度、DateTimeOriginal→DateTime），边缘数据一律安全返回空；5 项单测（手构造含 GPS 的最小 JPEG）覆盖。
- **导入链**：`PhotoImportService`——EXIF 解析 → 内容哈希落盘（重复内容不再新增也计 duplicates）→ `image` 包解码生成 ≤512px JPEG 缩略图 → 有 GPS 时自动绑定 300m 内最近标记 → `GuideEditor.addPhotos` 批量落库。无 GPS 照片进「未定位」栏（清单口径：M6-02 的「跳过」落地为跳过自动定位、支持 M6-03 手动绑定后补）。
- **照片墙页**：真 FlutterMap 底图（跟随攻略源，离线包源同样生效）、右下「仅照片/+标记/+路线」三 Chip 叠加切换、导入结果横幅、拍摄时间双向排序、AppBar 内多攻略切换与「清单」入口（已定位/未定位两栏、未定位行内绑定按钮）。
- **大图页**：InteractiveViewer 看原图（MediaStore 缓存）、顶栏重命名/删除（含确认，连文件+缓存）、底栏经纬度/无定位提示 + 「更改绑定」弹层（含距拍摄点距离与解除绑定）。
- **攻略地图页**：照片叠加层真数据化（圆形徽标=真缩略图、点击进大图页），无 GPS 且未绑定的照片不上图。
- **依赖**：新增 `image` 包（缩略图生成）。

### M6 改版 v2 记录（2026-10-20，用户反馈「进入照片墙不够直观」整体重构方案）

- **两级入口**：首页「照片墙」按钮现在进入**白板照片墙**（`photo_wall_gallery_page.dart`，地理/时间轴双模式）；原 M6 地图模式页保留为「地图照片浏览」模式页（`photo_wall_page.dart`，新增 `initialGuideIndex` 入参），由白板页选团后跳入，攻略内照片展示路径不变。
- **地理模式（默认）**：全部照片缩略图贴上白板——位置相近（≤150m 贪心聚类）自成一团随机叠加（围绕簇心偏移+旋转，最新压顶）；无定位照片补到剩余空槽。点团 → 整团高亮、其余淡出 → 底部操作条显示张数与主导归属攻略 +「进入地图照片浏览」（跳入该攻略地图模式）；无定位单点点击可「补定位/归属」（跨攻略标记选择弹层，绑定后账本条目以标记位置补位、攻略照片走编辑器绑定）。
- **时间轴模式**：按年分组、默认当年，底部滑轨（Slider）回溯历史年份；当年无照片显示空年提示，不影响滑轨回看。
