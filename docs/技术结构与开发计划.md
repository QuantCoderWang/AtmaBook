# TourGuider（旅行攻略地图本）技术结构与开发计划

> 版本：v1.0　|　日期：2026-10-19　|　对应开发流程：第 1 步（技术结构梳理）
> 形态：Flutter 无服务器（离线优先）应用，所有数据仅存本机

---

## 1. 应用定位一句话

一个 Notebook 风格的旅行攻略本：以地图为主画布标记"游玩/餐饮"等地点，图文信息写入标记点；
对"必去"点自动聚类成片区、配色并推荐游览路径；最终还能把带 GPS 的照片铺成地图照片墙。

## 3. 技术选型

| 事项 | 选择 | 理由 |
|------|------|------|
| 框架 | Flutter 3.47 stable（已安装） | 已具备环境 |
| 状态管理 | provider | 轻量、官方示例风格 |
| 地图渲染 | flutter_map + latlong2 | 支持任意 XYZ 瓦片源、自定义离线 TileProvider，无 SDK Key 依赖 |
| 本地存储 | path_provider + Dart File/JSON | 无服务器，纯文件存储 |
| 偏好设置 | shared_preferences | 记住默认地图源、聚类半径等 |
| 瓦片下载 | http | 并发下载 + 失败重试 |
| 图片处理 | image | 导入图片压缩、生成缩略图 |
| EXIF 读取 | exif（纯 Dart） | 提取照片 GPS 与拍摄时间，Windows/Android 通用 |
| 外跳导航 | url_launcher | geo: URI 唤起手机地图 App；桌面端降级为展示坐标 |
| 图片选择 | image_picker（移动端 Photo Picker，无需存储权限）；桌面端以 file_selector 降级 | 减少 Android 13+ 权限麻烦 |
| 测试 | flutter_test + flutter analyze | 第 3 步自动检查 |

> 坐标系说明：OSM/天地图/Esri 瓦片按 WGS-84 使用；高德/腾讯瓦片是 GCJ-02。
> 照片 EXIF 与标记录入统一存 **WGS-84**，切换到 GCJ-02 底图渲染时实时偏移换算，保证点位不漂移。

## 5. 本地数据设计（JSON）

### 5.1 磁盘布局（应用文档目录下 `tourguider/`）

```
tourguider/
├── guides/<guideId>.json          每篇攻略一个 JSON（图文+GPS 关联）
├── guides_index.json              首页卡片索引（防整目录扫描）
├── settings.json                  分类定义/自定义图标/默认地图源/聚类参数
├── pics/
│   ├── icons/                     用户自定义 pin 图标
│   ├── <guideId>/                 该攻略标记图片 + 封面
│   └── photowall/                 照片墙原图副本 + thumbs/ 缩略图
└── tiles/<packId>/{z}/{x}/{y}.png 离线瓦片 + pack.json
```

文件名用内容哈希（复制去重），JSON 内一律存**相对路径**，整个 `tourguider/` 文件夹可直接打包备份/迁移。

### 5.2 攻略 JSON 模板

```json
{
  "schemaVersion": 1,
  "id": "gd_a1b2c3",
  "title": "杭州两日游",
  "summary": "西湖+灵隐，主打步行",
  "createdAt": "2026-10-19T10:00:00Z",
  "updatedAt": "2026-10-19T12:30:00Z",
  "coverImage": "pics/gd_a1b2c3/cover_1.jpg",
  "settings": { "clusterRadiusM": 5000, "minPts": 2, "showRoutes": true },
  "markers": [
    {
      "id": "mk_x1", "title": "西湖·断桥残雪", "category": "scenic",
      "lat": 30.259145, "lng": 120.150890,
      "mustVisit": true,
      "description": "早上8点前人少，适合拍照",
      "images": ["pics/gd_a1b2c3/mk_x1_1.jpg", "pics/gd_a1b2c3/mk_x1_2.jpg"],
      "links": [{ "title": "官方介绍", "url": "https://example.com/duanqiao" }],
      "pin": { "iconRef": "builtin:landmark", "color": "#E91E63" }
    }
  ],
  "photos": [
    { "id": "ph_z1", "file": "pics/photowall/9f27....jpg", "lat": 30.2489, "lng": 120.1432, "takenAt": "2026-05-01T09:12:00Z" }
  ]
}
```

要点：
- 标记/图片/链接/GPS 同挂在一个 marker 对象上，天然关联；
- `pin.iconRef` 支持 `builtin:<图标代号>` 与 `custom:<pics/icons 文件名>`；
- 坐标统一 WGS-84 十进制度；`mustVisit` 是聚类算法的输入开关。

## 6. 关键算法

### 6.1 片区聚类（F8）
- 算法：**DBSCAN**(eps = 5000m 默认，设置页 1–20km 自由调整, minPts = 2)，距离用 Haversine；
- 簇 = 片区；噪声点（孤立点）各自单独成一个簇，同样配色；
- 只统计 `mustVisit == true` 的标记；选去点不参与，但会照常展示。

### 6.2 片区内最佳推荐路径（F8）
- 开放路径 TSP 启发式：**最近邻构造 + 2-opt 迭代优化**（n 个必去点规模很小，毫秒级）；
- 起点默认取片区内最北/最先创建的点，后续可扩展手动指定起点；
- 片区之间用灰色虚线按质心最近邻顺序示意衔接顺序（可关）。

### 6.3 片区配色
- 按簇大小降序，在 HSV 色环均匀取色（hue = i*360/n，s≈0.65，v≈0.9），
  片区颜色同时用于：连线、片区图例、该片区内必去 pin 的外圈。

### 6.4 地图源智能推荐
- 判断依据为新攻略的标记落点（而非 IP 归属）：**中国境内默认高德（GCJ-02 渲染换算），境外默认 OpenStreetMap**；
- 攻略内可随时手动切换源；首个标记添加前给出提示让用户选择。

### 6.5 坐标换算
- WGS84→GCJ02 标准偏移算法； 只做单向近似换算（往返误差 <1m，满足显示需求）。

### 6.6 瓦片数学
- lat/lng ↔ slippy tile (z/x/y)：下载与离线命中都靠它；对 GCJ-02 源需把 WGS84 经纬度换算后再算瓦片号。

## 7. 离线瓦片下载方案（F9）

- 支持源（第一批）：

| 源 | URL 模板 | 坐标系 | 备注 |
|----|----------|--------|------|
| OpenStreetMap | tile.openstreetmap.org/{z}/{x}/{y}.png | WGS84/球面墨卡托 | 全球，免费，需遵守下载礼节（限速+UA） | 境外默认 |
| 高德矢量 | webst01-04.is.autonavi.com/appmaptile?style=7… | GCJ-02 | 国内街景细节好 | 境内默认 |
| 高德卫星 | 同上 style=6 | GCJ-02 | 卫星影像 |
| 天地图矢量/影像 | DataServer?T=vec_w/…&tk=KEY | CGCS2000≈WGS84 | 需免费申请 tk，设置页可填 |
| Esri World Imagery | arcgisonline.com/.../tile/{z}/{y}/{x} | WGS84 | 全球卫星影像 |

- 下载流程：选源 → 地图上点两角画矩形 → 勾选 zoom 区间(如 10–17) → 预估张数（>8000 需二次确认）→
  并发 4、批量间隔节流、失败重试 2 次 → 落盘 `{z}/{x}/{y}.png` + pack.json；
- 在线/离线切换：地图页顶部地图源选择器；勾选离线包即切换 TileProvider，缺瓦片显示灰色回退块；
- 合规提示：所下载瓦片仅供个人离线使用，应用内标注来源版权。

## 10. 风险与对策

| 风险 | 对策 |
|------|------|
| 瓦片源限速/变更 | 下载器节流+UA+重试；源配置集中在 constants，坏源可快速换 |
| 国产相册导出照片可能被剥 EXIF | 跳过无 GPS 并在结果页明确计数提示 |
| 大量照片/标记性能 | 缩略图缓存、瓦片缓存、列表分页 |
| GCJ-02 显示漂移 | 所有存储 WGS84，渲染时按源实时换算 |
| 天地图需申请 tk | 设置页留配置项，默认源不用 key |
