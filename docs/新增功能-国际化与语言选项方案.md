## 一、最终架构（实现态）

- **取词双通道**：
  - UI：`AppLocalizations.of(context).xxx`；async gap 后固定 `if (!mounted) return; final t2 = AppLocalizations.of(context);`
  - 服务层：`I18nService.t`（`lib/core/i18n_service.dart`，静态 getter，未初始化回退中文模板）；由 app.dart 的 `localeResolutionCallback` 统一同步。
- **词典**：`lib/l10n/app_zh.arb`（模板）/ `app_en.arb`；占位符一律**位置参数**（String/int）；键格式 `camelCase` + 功能域前缀。
- **数据层中文常量不迁移**，UI 经 `core/i18n_names.dart` 助手映射：`categoryName(t,cat)` / `zoneDisplayName` / `mapSourceName(t,src)` / `mapKindName`。
- **底图 attribution**：全局 `_baseAttributionNote` 初值空串；`_BaseTile` 在 `didChangeDependencies` 写入，**必须经 `addPostFrameCallback` 帧末写入**（同步写会在首帧 build 期触发 ValueListenableBuilder 的 setState 断言）。

## 六、完工后追加批次（v2.0 修订 · 2026-10-24 已完成并验收）

验收中发现的两个问题，已按新批次循环完成修复（analyze 0 / 76 测试全绿 / flutter run 干净通过，用户已确认）：

1. **相册地理地图新条目不显示（要放大才出现）** — 根因：`photo_wall_gallery_page.dart` 的 `_reloadLedgerAndMaybeScan` 加载完账本后漏调 `_refreshVisible()`。地图首帧 `onMapReady` 先于异步账本加载，此刻 `_visible` 只含攻略照片（同步来源），账本条目（`w:`）要等第一次地图手势事件才补进视口集合。修复：账本加载后补一次 `_refreshVisible()`。顺带修掉 P5 遗留断言：`_BaseTile.didChangeDependencies` 同步写 attribution `ValueNotifier` 触发 build 期 setState——改为 `addPostFrameCallback` 帧末写入 + 值去重。
2. **相册库「剔除」** — 原行尾「地图显示」开关改为明确的**剔除按钮**（眼睛划线图标）：剔除后从相册库列表 / 地理相册地图 / 查看器同步消失，**不删除原始文件**；提示「已剔除，原文件保留」+ SnackBar「撤销」；AppBar「管理已剔除」面板支持逐条恢复显示 / 全部恢复。新增 10 条 i18n 词条（中英双份）。
